# Development and project direction

Air Neo is an evolving, software-first spatial display project for RayNeo AR glasses and Windows PCs.

## Project goals

The project explores:

- Spatial viewing and 3DoF-style positioning where device and software interfaces support it.
- Multiple virtual desktop screens.
- Window size, distance and placement customization.
- More usable multitasking and application management.
- A clean, approachable interface.
- A PC-first experience that does not require a dedicated external processing accessory for its core workflow.

These are project goals, not a promise that each feature is available in the current build.

## Current known issues

The repository README currently lists:

- Virtual window clicks are not functional.
- Aspect-ratio handling is unreliable.

See [Troubleshooting](troubleshooting.md) for details.

## Contributing and feedback

Ideas, bug reports and contributions are welcome.

For a useful bug report, provide the glasses model, Windows version, steps to reproduce, expected result, actual result and any relevant error messages.

Use the repository's [GitHub Issues](https://github.com/AverageDev143/Air-Neo/issues) to report bugs or suggest improvements. Review the source and README before making assumptions about implementation details.

## Release notes

The downloadable Windows package is published through [GitHub Releases](https://github.com/AverageDev143/Air-Neo/releases). Check the latest release notes for the build you are using.
