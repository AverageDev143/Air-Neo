Documentation / Air Neo

Development & roadmap

Air Neo explores a PC-first spatial desktop experience for RayNeo glasses. Project goals include spatial viewing, virtual screens, window placement and customization. These are goals, not a claim that every feature is already available. Read the source repository, check the release notes, and use GitHub Issues for bugs and suggestions. Air Neo is independent and is not affiliated with RayNeo.
