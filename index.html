The idea

More room to think.
More ways to work.

Your glasses are a display. Air Neo explores what happens when your desktop starts to feel like a space instead of a single screen.

The goal is to make spatial computing more approachable: useful windows, intuitive controls and customization that lives on the PC you already own.

  • ✳Built around a software-first approach
  • ✳Designed with multitasking in mind
  • ✳Open development, free to explore

Device & platform

Made with RayNeo in mind.

Air Neo is intended for RayNeo AR glasses connected to a Windows PC. The RayNeo Air 3S Pro has been used for project testing. Compatibility and feature support can vary by glasses model and PC setup.

Good to know

Questions, answered.

A little clarity before you jump in.

Is Air Neo free?

Yes. Air Neo is an independent, free community project. You can explore the source code and download the project from GitHub.

Does it work with every RayNeo model?

Not necessarily. Compatibility depends on the glasses model, available interfaces and software support. The RayNeo Air 3S Pro is one device used during development; support for other models is not guaranteed.

Are all the features ready?

No. Air Neo is actively evolving. Spatial viewing, virtual screens and other capabilities describe the project's goals; not every feature is implemented or supported yet. Check the repository for the latest state.

What do I need to run it?

A Windows PC, Python 3 and compatible RayNeo glasses. The launcher can create its local virtual environment and install the core Python requirements on first launch. See the README for exact setup steps.

Is Air Neo affiliated with RayNeo?

No. Air Neo is an independent community project and is not affiliated with, endorsed by or officially supported by RayNeo or InAir.

Where can I report a bug or contribute?

Visit the GitHub repository to explore the code, open an issue or follow development. Include your glasses model, Windows version, what you expected and what happened.
